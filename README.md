# 🌍 Геополитика — RP-бот для Telegram-групп

Ролевая игра за реальные современные страны. Игроки в группе разбирают страны, проводят реформы (открытые и тайные), ведут внешнюю политику, заключают договоры, вводят санкции, воюют и голосуют в ООН. ИИ-ведущий (Claude) просчитывает последствия, пишет мировые новости и присылает каждому лидеру секретный доклад.

## Возможности

- **Любая реальная страна** — `/take Бразилия`: ИИ сам выставляет стартовые показатели по реальным данным.
- **9 показателей**: ВВП, казна, население, стабильность, рейтинг власти, армия, технологии, коррупция, влияние + индекс силы.
- **Тайные действия** в личке (`/secret`) — незаметные реформы, спецоперации, шпионаж. Их не видит никто, но есть риск утечки и международного скандала.
- **Дипломатия**: договоры с игроками (кнопки «Принять / Отклонить») и со странами под управлением ИИ — их МИД отвечает сам, исходя из реальных интересов.
- **Санкции и войны** — исход зависит от армии, экономики, союзов.
- **ООН**: резолюции с голосованием кнопками.
- **ИИ-советник** — личный совет по текущей ситуации.
- **Ходы по кварталам**, мировые события, рейтинг держав, падение правительства при обвале стабильности.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите ключ Claude API в [Anthropic Console](https://console.anthropic.com/).
3. Установите и запустите:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и ANTHROPIC_API_KEY
python -m bot
```

4. Добавьте бота в группу (лучше админом — тогда он сможет удалять случайные `/secret` в общем чате) и напишите `/newgame`.

Модель по умолчанию — `claude-opus-5-5`. Чтобы игра обходилась дешевле, поставьте `AI_MODEL=claude-sonnet-5-5`.

## Как играть

1. Админ: `/newgame`.
2. Каждый игрок: `/take <страна>` и нажать кнопку «Открыть канал секретной связи» (иначе бот не сможет писать в личку).
3. Отдавайте приказы: `/reform`, `/foreign`, `/propose`, `/sanction`, `/war`, `/un`, а в личке боту — `/secret`.
4. Когда закончили — `/ready`. Ход считается, когда готовы все (или админ жмёт `/endturn`).
5. В группе выходят мировые новости, каждому в личку приходит секретный доклад.

Полный список команд — `/help`.
