# 🌍 Геополитика — RP-бот для Telegram-групп

Ролевая игра за реальные современные страны в одном большом чате (плюс отдельные залы для мирных конференций). Игроки разбирают страны, проводят реформы (открытые и тайные), ведут дипломатию, воюют через генералов и переписываются. Остальными странами управляет ИИ (Claude): они отвечают, заключают договоры и сами пишут в чат. ИИ-ведущий придумывает события (эпидемии, катастрофы, кризисы), считает последствия и рисует новости.

## Возможности

- **Умная карта мира** — 200 реальных стран, ~4000 провинций-шестиугольников, нарезанных по настоящим границам, с городами и столицами (данные Natural Earth). Захваченные земли заштрихованы цветом прежнего владельца, линия фронта прорисовывается красным, видны генералы и столицы. `/map`, `/map Украина` (крупно, с номерами провинций), `/map события`.
- **Генералы воюют сами.** При объявлении войны каждой стороне назначается генерал с характером и навыком. Вы даёте приказ («наступать на столицу», «держать оборону у Харькова»), а ИИ-штаб умно планирует удары: концентрирует силы, освобождает свои земли, окружает. Бои считаются движком игры с учётом армии, экономики, технологий, укреплений городов и столиц, проливов и десантов. Отрезанные мелкие «котлы» сдаются. Генералы набирают опыт, а могут и погибнуть.
- **Границы двигаются.** Взятые провинции переходят к занявшему. Если пала столица, правительство эвакуируется в другой город. Страна, потерявшая все провинции, перестаёт существовать.
- **Договоры с двумя подписями.** Любой договор (`/propose`), мир (`/peace` — по линии фронта или с возвратом к довоенным границам), передача провинций (`/transfer`, `/demand`) вступают в силу только после того, как подпишут **обе** страны. Страны-ИИ решают сами, исходя из своих интересов.
- **Мирные конференции в отдельном чате.** `/conference Россия, Турция | мирные переговоры` — бот берёт свободную комнату переговоров, переименовывает её, создаёт ссылку-приглашение и пускает **только** лидеров стран-участниц (заявки остальных отклоняются). Страны под управлением ИИ участвуют как делегации и отвечают, когда к ним обращаются. Команда `/draft`: ИИ-секретариат анализирует стенограмму и составляет договор (мир, передача провинций, выплаты, союзы и любые другие условия — демилитаризация, гарантии, торговля, обмен пленными…). Договор вступает в силу, только когда подписали **все** стороны; бот сам всё исполняет, публикует итоги в общем чате, а ведущий учитывает обязательства в следующих ходах. После этого комната очищается и готова к следующей конференции.
- **Один большой чат.** Страны переписываются (`/say`), страны-ИИ отвечают и после каждого хода сами делают заявления. Это можно выключить в `/settings`, тогда играют только игроки.
- **События.** ИИ придумывает эпидемии, катастрофы и кризисы, которые длятся несколько ходов и распространяются. Страны могут помогать друг другу (`/aid`), вводить карантин реформами и голосовать в ООН. Админ может запустить своё событие: `/event`. Случайные события тоже отключаются в `/settings`.
- **Тайные действия** в личке (`/secret`), ИИ-советник, 9 показателей страны, рейтинг держав, падение правительства при обвале стабильности.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите ключ Claude API в [Anthropic Console](https://console.anthropic.com/).
3. Установите и запустите:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # впишите BOT_TOKEN и ANTHROPIC_API_KEY
python -m bot
```

При первом запуске бот секунд за 5 строит провинции и кэширует их в `bot/data/cache/`.

4. Добавьте бота в группу (лучше админом, тогда он сможет удалять случайные `/secret` в общем чате) и напишите `/newgame`.

Модель по умолчанию — `claude-opus-5-5`. Чтобы игра обходилась дешевле, поставьте `AI_MODEL=claude-sonnet-5-5`.

### Комнаты для конференций

Боты Telegram не умеют создавать группы, поэтому комнату один раз создаёт админ:
1. В игровой группе: `/addroom` — бот покажет инструкцию и ID.
2. Создайте пустую группу, добавьте бота **администратором** (приглашать по ссылке, блокировать, удалять сообщения, менять информацию).
3. В новой группе: `/room <ID игровой группы>`.

Можно подключить несколько комнат — тогда несколько конференций идут параллельно.

### OpenRouter вместо Claude API

```env
AI_PROVIDER=openrouter
OPENROUTER_API_KEY=sk-or-...
AI_MODEL=<ID модели из https://openrouter.ai/models>
```

Лучше выбирать модель с поддержкой structured outputs (JSON schema) — тогда ответы ведущего всегда корректны. Если модель её не поддерживает, бот автоматически попросит JSON текстом.

## Как играть

1. Админ: `/newgame`, по желанию `/settings`.
2. Каждый игрок: `/take <страна>` и кнопка «Открыть канал секретной связи» (иначе бот не сможет писать в личку).
3. Отдавайте приказы: `/reform`, `/foreign`, `/say`, `/aid`, `/propose`, `/sanction`, `/war`, `/un`, а в личке боту — `/secret`.
4. На войне: `/generals`, `/command #id | приказ`, `/hire`. Смотрите фронт: `/map <страна>`.
   Для переговоров: `/conference <страны> | <тема>`, в зале — переговоры и `/draft`.
5. Когда закончили — `/ready`. Ход считается, когда готовы все (или админ жмёт `/endturn`): сначала генералы проводят операции, потом ведущий пишет новости, присылает карту и секретные доклады.

Полный список команд — `/help`.

## Данные карты

`bot/data/world.json` и `bot/data/cities.json` собраны скриптом `tools/build_map_data.py` из [Natural Earth](https://www.naturalearthdata.com/) (public domain).
